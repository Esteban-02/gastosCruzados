# gastosCruzados
# 💰 Gestor de Finanzas Personales

Aplicación web para la gestión y organización de las finanzas personales, diseñada para ayudar a llevar un control claro del dinero, comprender los hábitos de consumo y planificar objetivos financieros.

El proyecto busca centralizar el registro de ingresos y gastos, la clasificación de movimientos por categorías, el seguimiento de gastos fijos mensuales y la planificación de metas de ahorro, ofreciendo herramientas visuales que permitan comprender mejor cómo se administra el dinero.

## 🎯 Objetivos del proyecto

* Registrar y organizar ingresos y gastos personales.
* Clasificar los movimientos financieros por categorías.
* Controlar los gastos fijos y recurrentes.
* Crear metas de ahorro y realizar seguimiento de su progreso.
* Visualizar el comportamiento de las finanzas personales.
* Generar informes que faciliten la toma de decisiones.
* Incorporar herramientas inteligentes para analizar hábitos financieros y ofrecer recomendaciones.

## 🛠️ Hoja de ruta

El desarrollo se realizará de forma incremental, incorporando funcionalidades en diferentes versiones para facilitar el aprendizaje, la evolución del proyecto y el seguimiento de los cambios mediante Git.

### V1 — Gestión básica de finanzas

* Aplicación web responsive, adaptable a dispositivos móviles, tabletas y computadores.
* Registro, consulta, actualización y eliminación de ingresos y gastos.
* Administración de categorías financieras.
* Creación y gestión de metas de ahorro.
* Registro y organización de gastos fijos mensuales.
* Interfaz intuitiva para administrar la información financiera.

### V2 — Dashboard y visualización

* Dashboard con un resumen del estado financiero.
* Gráficas de ingresos, gastos y distribución por categorías.
* Indicadores de cumplimiento de metas de ahorro.
* Notificaciones y alertas relacionadas con gastos y objetivos financieros.
* Mejoras en la experiencia de usuario.

### V3 — Informes financieros

* Informes de ingresos y gastos por periodos.
* Comparación del comportamiento financiero entre meses.
* Análisis de gastos por categorías.
* Seguimiento del cumplimiento de metas de ahorro.
* Opciones para consultar y exportar informes.

### V4 — Aplicación para Android

* Desarrollo de una aplicación móvil para Android.
* Adaptación de las funcionalidades principales a dispositivos móviles.
* Integración con los servicios y datos de la aplicación.
* Experiencia de usuario optimizada para el uso desde el teléfono.

### V5 — Integración de inteligencia artificial

* Análisis inteligente de hábitos de consumo.
* Identificación de patrones y tendencias en los gastos.
* Generación de informes personalizados.
* Recomendaciones para mejorar la administración del dinero.
* Seguimiento inteligente de metas y posibles oportunidades de ahorro.

## 📌 Estado del proyecto

Proyecto en desarrollo. Las funcionalidades se implementarán progresivamente según la hoja de ruta definida.

## 🚀 Visión a futuro

Construir una herramienta de finanzas personales que permita comprender mejor los hábitos financieros, planificar objetivos y tomar decisiones más informadas sobre el uso del dinero.
